#  Микросервисная платформа управления пользователями

Полноценная микросервисная архитектура, реализующая ключевые паттерны Spring Cloud для управления пользователями и асинхронной отправки email-уведомлений. Проект упакован в monorepo для удобства сквозного тестирования и оркестрации.

## Архитектура системы

```text
Client (Browser / Postman)
      │
      ▼
┌───────────────────────────┐
│      API Gateway          │ :8080 (Роутинг, CORS, Aggregated Swagger)
└─────────────┬─────────────┘
              │ lb:// (Service Discovery)
┌─────────────┴─────────────┐                ┌────────────────────────┐
│     Eureka Server         │◄───────────────┤    Config Server       │
│         :8761             │  (Реестр)      │        :8888           │
└─────────────┬─────────────┘                └────────────────────────┘
              │
┌─────────────┴──────────────────────────────────────────────┐
▼                                                            ▼
┌─────────────────────────┐                    ┌─────────────────────────┐
│     User Service        │  События Kafka     │  Notification Service   │
│         :8081           │ ─────────────────► │         :8082           │
│ (CRUD, HATEOAS, CB)     │                    │ (SMTP Consumer, CB)     │
└─────────────┬───────────┘                    └─────────────┬───────────┘
              │                                              │
┌─────────────┴───────────┐                    ┌─────────────┴───────────┐
│      PostgreSQL         │                    │        Mailpit          │
│         :5432           │                    │  :1025 (SMTP) / :8025   │
└─────────────────────────┘                    └─────────────────────────┘

**Запуск всей системы**

Выполнить в корневой директории проекта:
docker compose up -d --build

**Проверка работоспособности:**

**Реестр сервисов:**
Открыть http://localhost:8761. Должно быть 3 сервиса со статусом UP: API-GATEWAY, USER-SERVICE, NOTIFICATION-SERVICE.

**API Документация:**
Открыть http://localhost:8080/swagger-ui.html.
Выбрать user-service в выпадающем списке.
Убедиться, что Request URL указывает на http://localhost:8080 (Gateway).
Выполнить POST /api/v1/users для создания пользователя.

**Проверка уведомлений:**
Открыть http://localhost:8025 (Mailpit UI). Там должно появиться новое письмо о создании пользователя.
